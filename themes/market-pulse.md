# Theme: Market Pulse (Fiverr-inspired)

**Status:** Draft / v1. A deliberately *opposite* language to Connected Calm.
**Inspiration:** Fiverr iOS design language (vivid green, near-black ink, white
surfaces, capsule buttons, bold heavy type, solid filled icons). The exact
Mobbin reference screens could not be scraped (paywall) — built from Fiverr's
documented visual system; refine with a screenshot if exact fidelity needed.
**Mockup:** `../sketch-mockup/theme-fiverr.html` + `../sketch-mockup/theme-fiverr.png`.

## Palette
| Token | Hex | Role |
|---|---|---|
| Fiverr Green | `#1DBF73` | Anchor — logo, active states, primary CTA, progress |
| Green Dark | `#15A866` | Verified text, active-tab text, icon strokes on light |
| Green Soft | `#E7F7EF` | Verified / matched badges, active chip tint |
| Ink | `#404145` | Near-black primary text (Fiverr charcoal) |
| Ink Soft | `#74767E` | Secondary text, inactive nav |
| Line | `#E4E5E7` | Hairline borders |
| Canvas | `#F7F7F8` | App background (light gray) |
| Paper | `#FFFFFF` | Cards, sheets, fields |
| Risk Red | `#E0312B` | Destructive / scam-risk ONLY |

## Visual Language
- **Mood:** energetic, bold, confident, marketplace. Action-forward.
- **Surfaces:** white cards on light-gray canvas, 1px hairline border, subtle
  soft shadow. Slightly more "lifted" than Connected Calm but still flat.
- **Typography:** Urbanist (display/headings) + Jost (body), but pushed **heavy**
  (800 weight headings, tight tracking). Uppercase eyebrow labels at 800 weight,
  0.1em tracking — louder than Connected Calm's quiet labels.
- **Icons:** **solid filled, bold.** No thin strokes. Inactive = gray fill;
  active = green fill. Rounded joins for friendliness.
- **Buttons:** **capsule (full pill)** green primary with white bold text and a
  soft green glow shadow. The "Apply" action is green (Fiverr's whole brand is
  green — so the happy moment is the brand color here, not a separate gold).
- **Navbar:** active tab = solid green filled icon + green bold label. No
  underline; the fill *is* the spotlight. Four tabs (Jobs, Applications,
  Passport, Help).

## Contrast with Connected Calm
| Axis | Connected Calm | Market Pulse |
|---|---|---|
| Anchor | Soft Purple `#6B5B95` | Fiverr Green `#1DBF73` |
| Apply action | Gold (separate) | Green (brand) |
| Icons | Thin 1.5px line, no fill | Solid filled bold |
| Type | Calm, 700 headings | Bold, 800 headings |
| Navbar | Purple underline | Green filled active |
| Mood | Relaxed / low-pressure | Energetic / action-forward |

## When to use
A/B testing a higher-energy variant, or for audiences/markets that respond to
bold marketplace aesthetics. Keep Khmer-first + verification/safety copy intact.
